4 Non-Negotiable Regulatory Guardrails

Built for the Australian regulatory regime (ACMA, TCP Code & Australian Privacy Principles).

🔒 1. Consent First (AU Two-Party)

Discloses call recording at second 0 before collecting any customer information. Complies with the Telecommunications (Interception and Access) Act.

💳 2. No Card Data by Voice (PCI-DSS)

The agent interrupts mid-sequence if a customer starts reading card digits, then escalates with trigger SENSITIVE. Card data is never requested, accepted, or repeated back. Secure web checkout link is dispatched instead.

📵 3. Do-Not-Call Aware (ACMA)

An executable gate, not a claim: checkDncLocal() runs before dialling and disables the call button. Register listings are a hard block; the calling-hours window is overridable only with a logged acknowledgement. Stubbed register — swap for the ACMA washing API in production.

🛑 4. Respect "No" (Zero Pressure)

A single decline or statement of disinterest terminates the call immediately with polite sign-off. Zero badgering loops.
